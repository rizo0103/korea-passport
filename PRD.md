# 1. Overview

## 1.1 Product Summary

Korea Passport — это мобильная геймифицированная платформа для изучения корейского языка, основанная на концепции путешествия по Южной Корее.

Пользователь проходит обучение через:

* уроки (Lessons),
* задания (Missions),
* практику (Practice),
* соревновательные дуэли (Word Duel),
* систему прогресса (Passport, Cities, Visa, Stamps).

---

## 1.2 Product Goals

### Primary Goals

* Повысить регулярность изучения языка.
* Увеличить мотивацию через игровые механики.
* Создать устойчивую привычку ежедневного обучения.
* Интегрировать обучение в экосистему Корейского центра.

### Secondary Goals

* Поддержка будущего масштабирования на другие языки.
* Возможность подключения других образовательных центров.
* Создание платформы с долгосрочной архитектурой.

---

## 1.3 Success Metrics

Продукт считается успешным, если:

* ≥ 60% пользователей возвращаются ежедневно (DAU retention).
* Средняя сессия ≥ 3–10 минут.
* Пользователи завершают хотя бы 1 Mission в день.
* Word Duel используется регулярно как мотивационный элемент.
* Учителя используют систему как часть обучения.

# 2. User Personas

## 2.1 Student (Primary User)

* Возраст: 12–25
* Уровень: beginner → intermediate
* Мотивация: экзамены, интерес к Корее, дорамы, культура
* Проблема: теряет мотивацию между занятиями

---

## 2.2 Teacher (Secondary User)

* Управляет заданиями и прогрессом
* Создаёт уроки и миссии
* Использует систему для мотивации группы

---

## 2.3 Admin (System Role)

* Управляет контентом
* Контролирует города, задания и баланс
* Поддерживает систему

---

# 3. Functional Requirements

## 3.1 Authentication

* Регистрация пользователя
* Вход в систему
* Профиль пользователя
* Роль пользователя (Student / Teacher / Admin)

---

## 3.2 Passport System

* Отображение текущего прогресса
* Список городов
* Заблокированные / открытые города
* Прогресс до следующей визы
* История штампов

---

## 3.3 City System

* Каждый город связан с набором тем
* Город открывается после выполнения условий
* Город содержит:

  * Lessons
  * Missions
  * Practice

---

## 3.4 Lesson System

* Теоретические материалы:

  * слова
  * грамматика
  * диалоги
* Прогресс внутри урока
* Завершение урока даёт XP

---

## 3.5 Mission System

* Задания внутри города
* Типы:

  * выучить слова
  * пройти тест
  * завершить урок
  * победить в дуэлях
* Даёт XP + прогресс Visa

---

## 3.6 Practice System

* Необязательные упражнения
* Закрепление материала
* Без влияния на прогресс (если не указано)

---

## 3.7 Word Duel System (Core Feature)

* PvP режим между пользователями
* Типы дуэлей:

  * перевод
  * аудирование
  * набор текста
  * выбор ответа

### Результаты:

* победа → XP + Coins
* поражение → минимальный XP
* влияет на Visa progress

---

## 3.8 Reward System

* XP (опыт)
* Coins (валюта)
* Stamps (коллекция достижений)
* Achievements (системные награды)

---

## 3.9 Visa System

* Пропуск в следующий город
* Требует:

  * XP
  * Mission completion
  * Word Duel wins (опционально)
* Основной механизм прогресса

---

## 3.10 Daily System

* Daily Challenge
* Daily Reward
* Streak system (серия дней)
* Обновление каждые 24 часа

---

## 3.11 Leaderboard System

* Рейтинг пользователей
* Рейтинг по дуэлям
* Рейтинг по XP
* Рейтинг по центру (группы)

---

## 3.12 Center Integration (Important)

* Группы студентов
* Турниры центра
* Привязка к учителям
* Централизованные задания

---

# 4. Non-Functional Requirements

## 4.1 Performance

* Время загрузки < 2–3 секунд
* Дуэли должны работать без задержек
* Поддержка слабых устройств

---

## 4.2 Scalability

* Архитектура должна поддерживать:

  * отдельный центр
  * несколько центров
  * будущую глобализацию

---

## 4.3 Cost Constraints

* Минимальное использование платных сервисов
* Без AI в MVP
* Firebase/Supabase как основной backend

---

## 4.4 Maintainability

* Чёткая модульная структура
* Разделение логики:

  * auth
  * game logic
  * learning system
* Документированная архитектура

---

## 4.5 Security

* Базовая защита аккаунтов
* Проверка данных на backend
* Защита от читинга в дуэлях (минимальная логика)

---

# 5. MVP Scope (Version 1.0)

## Included:

* Authentication
* Passport system (basic)
* 2–3 Cities
* Lessons
* Missions
* Word Duel (basic mode)
* XP system
* Coins system
* Basic UI

---

## Excluded (future versions):

* Marketplace

# 7. Key Product Principles

1. Обучение всегда связано с прогрессом.
2. Игровые механики усиливают обучение, а не заменяют его.
3. Пользователь всегда понимает свой следующий шаг.
4. Минимум сложных экранов — максимум понятной логики.
5. Каждое действие даёт ощущение движения вперёд.

---

# 8. Risks

## 8.1 Motivation Drop

Если Core Loop не работает, пользователи перестают возвращаться.

## 8.2 Overcomplexity

Слишком много механик может сломать фокус продукта.

## 8.3 Server Cost Growth

Word Duel и лидерборды могут увеличить нагрузку.

## 8.4 Scope Creep

Риск добавления лишних функций вне Vision.

# 10. Final Statement

Korea Passport — это не образовательное приложение.

Это система, которая превращает изучение языка в прогрессирующее путешествие.

Каждая функция должна усиливать ощущение движения по Корее.
