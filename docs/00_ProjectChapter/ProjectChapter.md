# 1. Background

В Корейском центре ученики изучают корейский язык, посещают занятия, выполняют домашние задания и готовятся к экзаменам.

Однако большая часть обучения происходит только во время уроков. Между занятиями многим ученикам сложно сохранять мотивацию регулярно повторять материал.

Большинство существующих приложений для изучения языка не связаны с жизнью нашего центра, преподавателями и другими учениками. Они предлагают одинаковый опыт для всех пользователей и редко создают ощущение принадлежности к сообществу.

Это стало основной причиной создания собственного мобильного приложения.

---

# 2. Purpose

Создать единую цифровую платформу, которая станет частью учебного процесса Корейского центра.

Приложение должно мотивировать учеников регулярно практиковать язык через игровые механики, дружеское соревнование и постепенное открытие нового контента.

---

# 3. Problem Statement

Сегодня процесс обучения вне занятий недостаточно вовлекает учеников.

Основные проблемы:

* отсутствие постоянной мотивации;
* низкая вовлеченность после уроков;
* отсутствие единого пространства для обучения и соревнований;
* использование нескольких разных приложений одновременно.

---

# 4. Proposed Solution

Создать мобильное приложение Korea Passport.

Вместо обычной системы уровней пользователь путешествует по Южной Корее.

Изучение новых тем позволяет открывать города.

Практика приносит опыт.

Победы в Word Duel помогают получать визы.

Достижения превращаются в штампы виртуального паспорта.

Обучение становится похожим на игру-путешествие.

---

# 5. Business Goal

На первом этапе приложение создается исключительно для Корейского центра.

В дальнейшем архитектура проекта должна позволять подключение других языковых школ без необходимости переписывать систему.

---

# 6. Success Criteria

Проект считается успешным, если:

* ученики регулярно используют приложение между занятиями;
* повышается вовлеченность в обучение;
* преподаватели начинают использовать приложение как часть образовательного процесса;
* платформа может поддерживаться и развиваться новыми разработчиками без полной переработки.

---

# 7. Constraints

Проект разрабатывается студентами.

Поэтому:

* минимальный бюджет;
* минимальные расходы на серверную инфраструктуру;
* отсутствие зависимости от дорогих AI-сервисов;
* использование бесплатных или недорогих технологий;
* простота сопровождения.

---

# 8. Long-Term Vision

Korea Passport должен стать долгосрочным образовательным проектом.

Проект создается таким образом, чтобы его можно было постепенно развивать, улучшать и передавать следующим поколениям разработчиков без потери качества архитектуры и документации.

---

# 9. Project Motto
