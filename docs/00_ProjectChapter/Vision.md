# 1. Vision

## 1.1 Product Vision

Korea Passport — это геймифицированная образовательная платформа для изучения корейского языка, основанная на концепции путешествия по Южной Корее.

Вместо традиционного подхода “урок → тест → оценка”, пользователь проходит путь путешественника, который открывает города, получает визы, участвует в языковых дуэлях и собирает штампы в виртуальном паспорте.

Цель продукта — превратить регулярное изучение языка в естественное, мотивирующее и эмоционально вовлекающее действие.

---

## 1.2 Vision Statement

Мы создаём систему, в которой изучение языка перестаёт быть обязанностью и становится прогрессирующим путешествием.

Пользователь не “учится корейскому” — он **двигается по Корее через язык**.

Каждое действие имеет смысл:

* каждое слово приближает к новому городу;
* каждая дуэль подтверждает навыки;
* каждый штамп фиксирует достижение;
* каждая визa открывает следующий этап путешествия.

---

## 1.3 Long-Term Vision

Korea Passport должен эволюционировать в платформу, которая:

* используется в образовательных центрах;
* поддерживает разные языки и курсы;
* позволяет преподавателям управлять контентом;
* создаёт единую игровую экосистему обучения.

В долгосрочной перспективе проект должен стать стандартом “игрового обучения” внутри языковых школ.

---

## 1.4 Product Identity

Korea Passport — это не приложение для изучения языка.

Это:

* образовательная игра;
* система прогресса;
* социальная среда обучения;
* цифровое путешествие.

---

# 2. Core Loop

## 2.1 Core Loop Overview

Core Loop описывает основную повторяющуюся структуру взаимодействия пользователя с приложением.

Это цикл, который пользователь проходит ежедневно.

---

## 2.2 Core Loop Diagram

```text id="coreloop1"
START

↓
Open App
↓
Check Passport (Progress / City / Visa status)
↓
Receive Daily Mission
↓
Study Lesson (Words / Grammar / Dialogue)
↓
Practice (Exercises)
↓
Word Duel (PvP or AI Challenge)
↓
Earn XP + Coins
↓
Unlock Progress (Mission / Stamp / Visa progress)
↓
Move closer to next City
↓
Return Tomorrow
```

---

## 2.3 Detailed Loop Breakdown

### 1. Entry Point

Пользователь открывает приложение и сразу видит:

* текущий город;
* прогресс до следующей визы;
* ежедневную цель.

Цель этапа — мгновенно дать ощущение прогресса.

---

### 2. Daily Mission

Система выдаёт ежедневное задание.

Примеры:

* выучить 10 слов;
* пройти 1 урок;
* выиграть 2 Word Duel.

Цель — направить пользователя.

---

### 3. Learning Phase (Lesson)

Пользователь изучает структурированный материал:

* слова;
* грамматику;
* выражения;
* диалоги.

Цель — получение знаний.

---

### 4. Practice Phase

Закрепление материала через упражнения:

* тесты;
* перевод;
* аудирование.

Цель — укрепление навыков.

---

### 5. Word Duel Phase

Игровая соревновательная часть.

Пользователь:

* соревнуется с другими учениками или системой;
* применяет изученное в реальном времени.

Цель — проверка знаний под давлением времени.

---

### 6. Reward Phase

После активности пользователь получает:

* XP;
* Coins;
* Progress toward Visa;
* Stamps (при достижениях).

Цель — закрепить мотивацию через награды.

---

### 7. Progression Phase

Система обновляет:

* прогресс города;
* статус визы;
* открытие новых миссий.

Цель — визуализировать развитие.

---

### 8. Return Loop

Пользователь получает:

* понимание следующего шага;
* причину вернуться завтра.

Цель — формирование привычки.

---

## 2.4 Core Design Principle

> Каждый цикл должен ощущаться как маленькое путешествие вперёд.

Если пользователь не чувствует прогресс — цикл считается сломанным.

---

## 2.5 Loop Frequency

Core Loop рассчитан на:

* 1–3 коротких сессии в день;
* 3–10 минут на сессию;
* регулярное возвращение без принуждения.

---

## 2.6 Emotional Loop Goal

Каждый цикл должен вызывать у пользователя одну эмоцию:

> “Я стал ближе к следующему городу.”

---

# 3. Connection Between Vision and Core Loop

Vision отвечает на вопрос:

> “Зачем существует продукт?”

Core Loop отвечает на вопрос:

> “Как пользователь ежедневно взаимодействует с продуктом?”

Обе части должны быть согласованы и не могут противоречить друг другу.

---

# 4. Success Interpretation

Если Core Loop работает правильно:

* пользователь возвращается ежедневно;
* обучение ощущается как прогресс;
* Word Duel становится мотивацией;
* города становятся символами достижений.

Если Core Loop не работает:

* приложение превращается в обычный учебник;
* пропадает мотивация;
* исчезает долгосрочная вовлечённость.
